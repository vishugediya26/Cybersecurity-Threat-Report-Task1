# Threat Intelligence Report: Modern Cyber Threats 2024–2025

Task-1 of the Maincrafts Technology Cybersecurity & Ethical Hacking Internship.
Author: Meenakshi Newar (MSc IT, Cyber Security)

## About
A threat intelligence report written from the viewpoint of a cybersecurity analyst intern. It reviews five major threats, how they harm individuals and organisations, a real incident for each, and practical defences.

## Threats covered
1. AI-powered phishing (case study: Arup deepfake fraud, 2024)
2. Ransomware-as-a-Service (case study: Change Healthcare, 2024)
3. Cloud security misconfigurations (case studies: Capital One 2019, Snowflake customers 2024)
4. IoT vulnerabilities (case study: Raptor Train botnet)
5. Zero-day exploits (case study: Ivanti Connect Secure, 2024)

## Contents
- Introduction to cybersecurity
- Threat analysis with impact, case study and preventive measures
- Defence summary and action plan
- Conclusion and future scope
- References
